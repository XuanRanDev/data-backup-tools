# 数据备份工具

面向 Windows 10/11 的离线备份整理工具，适合把相机/手机/录屏素材等按年月归档到外接硬盘。支持明文复制或加密 7z 归档，并提供校验与日志，方便长期离线存储。

## 功能与用途
- 按文件时间自动归类到 `YYYY/MM`（支持修改时间/创建时间/EXIF，EXIF 缺失自动回退）
- 明文复制或加密 7z 归档（AES-256，`-mhe=on`，`-mx=9`）
- 每月一个归档文件，自动生成 SHA256 校验文件
- 可选生成 PAR2 冗余文件（默认 5%）
- 预览分组统计、进度与预计剩余时间
- 统一日志 `BACKUP/_INDEX/BACKUP_LOG.csv`，并提供详细日志
- 明文模式下自动跳过已备份且相同的文件

适用场景：
- 摄影素材/录屏素材的离线归档
- 外接硬盘数据整理与长期保存
- 需要加密保存且可校验完整性的离线备份

## 目录结构
目标盘会自动创建如下结构：

```
<目标盘>\BACKUP\
  └─<YYYY>\
     └─<MM>\
        ├─<SourceType>\
        └─ENCRYPTED\
```

- 明文模式：文件复制到 `<SourceType>` 目录
- 加密模式：归档文件放在 `ENCRYPTED` 目录

## 依赖与环境
- Python 3.10+（建议 3.12）
- 依赖库：PySide6、Pillow
- 加密模式需要安装 7-Zip（`7z.exe`），程序会尝试自动发现
- PAR2 使用仓库内置的 `par2.exe`

安装依赖：
```bash
pip install PySide6 Pillow
```

## 运行
```bash
python main.py
```

## 使用流程
1. 添加源文件或文件夹（支持拖拽）
2. 选择目标盘与来源类型（可自定义）
3. 选择归类规则（修改时间/创建时间/EXIF）
4. 选择模式：明文复制 或 加密归档
5. 加密模式下填写密码并确认 7z.exe 路径
6. 预览分组统计后开始执行

完成后可使用“校验验证”重新计算 SHA256 并比对结果。

## 日志
- 主日志：`<目标盘>\BACKUP\_INDEX\BACKUP_LOG.csv`
- 详细日志：`<目标盘>\BACKUP\Logs\BACKUP_DETAIL_*.log`

字段包含时间戳、任务 ID、源路径、目标盘、年月、来源类型、模式、归档名、大小、SHA256 等。

## 配置说明
可在 `core/config.py` 中调整：
- 目录与归档命名规则
- 默认来源类型
- 日志字段定义
- 模式与时间规则常量

## 已知说明
- PAR2 仅在加密模式下可选生成（5%），用于增强归档容错
- 7-Zip 由系统安装提供，未找到时需手动选择
